## ⚡ Features

1. **Market Radar & Intelligence:** Real-time Solana token pair discovery, volume tracking, and liquidity dynamics.
2. **Trade Simulator & Check:** Model swaps, analyze slippage, fee tiers, and liquidity routes with Raydium integration.
3. **Portfolio & Exit Check:** Deep surveillance on token holdings, exit routes, and market depth without requiring wallet private keys.
4. **On-Chain Evidence & Verification:** Verify token mints, metadata, and contracts with direct Solscan explorer integration.
5. **Private Mode & Local Vault:** Zero tracking, client-side cryptographic storage, and private watchlists.
